App Structure — 4 Tabs

☰ Tab 1 — Checklist

Run the inspection — select site, mark rooms Good or Remarks. Draft auto-saved until submitted.

⚙ Tab 2 — Settings

Connect to Google Sheets or OneDrive, manage inspectors, configure alert delay and cloud provider.

📊 Tab 3 — Data

View all historical records, filter by date or site, export as CSV, and sync from cloud storage.

📖 Tab 4 — Read Me

Inspection guidelines, room status reference key, and version release notes.

Running an Inspection

1
Open the app → 1. tap the home screen icon (Mobile), 2. go to our SharedDrive (Desktop)
2
Select your building: 1800 / UPA / NAGA to show the rooms in Insection List
3
Click "DATE NOW" to auto-fill today's date & time
4
Select your name from the Inspector dropdown
5
For each room: tap ✓ Good or ✗ Remarks
6
For Issue rooms: pick a preset remark or type a custom note
7
Click "SUBMIT DETAILS"
8
Cloud sync fires automatically — alert scheduled if any rooms were Remarked

Cloud Sync & Automated Alerts

Cloud Providers Supported

  • Google Sheets (Apps Script Web App) — primary
  • Microsoft OneDrive (Power Automate Webhook)
  • Settings sync across all devices automatically

Data synced: Inspector list, alert delay, cloud provider, all inspection records

Automated Email Alerts

  • Fires X minutes after submission (configurable, default 2 min)
  • Only sends when rooms are marked Remarked / Remarks
  • Delivered server-side via Apps Script — works even when app is closed
  • Contains list of all remarked rooms with notes
  • Email sender: kotep1019@gmail.com (Checklist Team)
